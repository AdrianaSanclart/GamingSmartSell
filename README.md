## Objetivo do Software

O GamingSmartSell é um sistema desktop desenvolvido para auxiliar no gerenciamento de uma loja de produtos gamers. O software tem como objetivo facilitar o controle de produtos, fornecedores, estoque, vendas, usuários e relatórios, centralizando as principais operações da loja em uma única aplicação.

## Funcionalidades do Sistema

- Autenticação de usuários por e-mail e senha.
- Controle de acesso de acordo com o cargo do usuário: Administrador, Gerente e Vendedor.
- Cadastro, consulta, edição e desativação de usuários.
- Cadastro, consulta, edição e desativação de produtos.
- Cadastro, consulta, edição e desativação de fornecedores.
- Consulta e ajuste de estoque.
- Sincronização da quantidade dos produtos com o estoque.
- Registro de vendas.
- Atualização automática do estoque após a realização de uma venda.
- Estorno de vendas com devolução da quantidade ao estoque.
- Pesquisa de produtos, fornecedores, usuários e vendas.
- Geração de relatórios de vendas, estoque, produtos e usuários.
- Exportação de relatórios nos formatos CSV e Excel.
- Integração com banco de dados MySQL.
